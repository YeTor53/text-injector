# WebTry 文本注入器

把一段文本"打字"进任意窗口：网页输入框、在线编辑器、记事本、聊天框。
不用剪贴板、不改动目标程序；英文与符号走硬件扫描码，中文等字符走 Unicode 注入。

## 下载

免安装执行文件（Windows 64 位）：[Releases](https://github.com/YeTor53/text-injector/releases) 里的 `main.exe`，
双击即用，无需 Python 环境。

## 跑起来

- PyCharm：右击 `main.py` → Run（解释器用 Python 3.10，只用标准库，无需装依赖）
- 命令行：`python main.py`
- 打包：`pyinstaller main.spec --noconfirm` → `dist/main.exe`
  （打包前先关掉正在运行的 `main.exe`，否则覆盖会失败）

## 用法

1. 在编辑区里写文本，或 Ctrl+O 打开已有文件、Ctrl+S 保存
2. 选好「模式 / 间隔 / 倒计时 / 换行」
3. 点「开始注入」，趁倒计时把鼠标点到目标输入框上；倒计时结束就开始打字
4. 随时按 Esc、「停止」或全局热键（默认 F9）中断

## 模式

- 混合注入：原文注入。ASCII 走扫描码（不受输入法影响），中文等走 Unicode
- 代码模式：Tab 展开成 4 空格、行首缩进保留、行内连续空格压成一个、去行尾空白、连续空行压成一个
- 随机汉字：生成 10000 个随机汉字并插入 500 个换行（压力测试用）
- 等长乱码：按原文每行长度生成等长随机汉字，保留行结构

## 换行

- 三种发法可选：回车（默认）、Shift+回车（聊天框里换行而不发送）、换行符（直接发 Unicode \n）
- 文本里的 `\r\n` 与孤立 `\r` 一律当作一个换行，不会变成一个换行变两次回车

## 界面

- 编辑区：行号、当前行高亮、查找替换（Ctrl+F，支持区分大小写/全部替换）、字体字号、自动换行
- 全局热键可自定义：点右下角热键按钮，直接按下你想用的组合键（Ctrl / Alt / Shift / Win + 任意键）
- 配置存在 exe / 源码同目录的 `config.json`，下次启动自动恢复

## 参数实测（54 字混合文本：33 个符号 + 8 个汉字 + 2 个换行）

- 每批 8 字一次性下发（间隔 0ms）：只到 12 字
- 每批 1 字、间隔 0ms：17 字
- 逐字符 + 2ms：54 字全部到达（100%）

结论：默认「逐字符 + 2ms」。目标程序丢字就把「间隔」调大（5~10ms 更稳），追求速度可调小。

## 已知边界

- 以管理员权限运行的窗口（UIPI 保护）收不到普通权限进程的注入：把本程序也用管理员身份运行
- 用 DirectInput 独占键盘的游戏通常收不到这类注入
- 注入期间别动键盘，否则你的按键会混进目标窗口

## 目录

| 路径 | 作用 |
| --- | --- |
| `main.py` | 界面装配与调度（配置、打开/保存、倒计时、后台注入线程、热键） |
| `injector.py` | 注入层：扫描码表、SendInput 事件、四种模式的文本流生成 |
| `editor.py` | 编辑区组件：行号、查找替换、字体字号 |
| `hotkey.py` | 全局热键注册（Win32 RegisterHotKey，独立消息线程） |
| `scripts/injector_selfcheck.py` | 离线自检，346 项，不碰键盘：`python scripts/injector_selfcheck.py` |
| `assets/icon.ico` | 程序与窗口图标 |
| `config.json` | 首次运行自动生成（不入库） |
